About the Project

Food Maps is a restaurant discovery platform that helps users find places based on atmosphere, price range, and customer experiences rather than simple keyword matching.

By combining semantic search and review analysis, Food Maps provides more meaningful recommendations tailored to each user.

Key Features

  • Semantic vibe-based search
  • Review aggregation
  • Sentiment and aspect analysis
  • Personalized recommendations
  • Interactive restaurant map
